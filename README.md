# Zwiedzanie Trzebiatowa

Projekt wielowątkowej i wielozakończeniowej gry terenowej w Trzebiatowie oraz strony marketingowej prezentującej grę i umożliwiającej zakup, a później aktywację i obsługę konta.

Aktualny status: Etap 0 — fundament organizacyjny i dokumentacyjny. Implementacja jeszcze się nie rozpoczęła. Projekt ma docelowo być monorepo z osobnymi aplikacjami GAME PWA i WEBSITE.

Gra będzie mobile-first i offline-first, z decyzjami oraz wynikami zagadek wpływającymi na późniejszą narrację i kompozytowe zakończenia.
