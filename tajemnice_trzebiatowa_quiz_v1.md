# Tajemnice Trzebiatowa — Quiz decyzji projektowych v1
Quiz porządkujący otwarte decyzje dotyczące logiki, fabuły, kampanii, mechanik i wersji trylogii. Rekomendacja jest sugestią, nie automatycznym wyborem.
## Jak odpowiadać
Wybierz **A / B / C / Inne**. Opcja oznaczona **⭐** jest sugerowana na podstawie dotychczasowych ustaleń projektu. Rekomendacja nie jest automatycznie wiążąca. Przy „Inne” dopisz własną zasadę możliwie konkretnie.

Co ma być nadrzędnym doświadczeniem całej trylogii?

🟢 ✅ **Zalety:**

🔴 ❌ **Wady:**
